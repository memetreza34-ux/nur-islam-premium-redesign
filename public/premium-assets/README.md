# Nur Islam Premium Assets

Die App verwendet feste Pfade für die hochauflösenden Bildobjekte aus dem Chat. Solange eine PNG-Datei fehlt, rendert `PremiumVisuals.tsx` automatisch eine passende SVG-Fallback-Illustration.

## Zielordner

`public/premium-assets/high-res-objects/`

## Referenzboards

Die fünf Master-Boards bestimmen verbindlich:

- Smaragd-/Gold-Palette
- Typografie und Hierarchie
- Kartenradien und Abstände
- Navigation und Icon-Stil
- Einsatz von Moschee, Quran, Kaaba, Laterne, Halbmond, Rosette und Qibla-Kompass

Die Bilder werden nicht wahllos verteilt. Jedes Objekt erhält eine inhaltlich passende Rolle und wird so skaliert, dass die Oberfläche ruhig und hochwertig bleibt.
