## Wichtige Detailpunkte

### 61 · Al-Mumit

Quran 53:44 schreibt Allah direkt zu:

`وَأَنَّهُ هُوَ أَمَاتَ وَأَحْيَا`

Damit ist die zugrunde liegende Aussage — Allah gibt Tod und Leben — klar belegt. Der Audit trennt aber bewusst zwischen einer Handlung und einer als festes Nomen gelehrten Namensform.

**Urteil:** `variant-aware`, nicht entfernen.

### 64 · Al-Wajid

Die verbreitete Liste enthält `الْوَاجِدُ`. Im bisher geprüften starken Quran-/Sahih-Material wurde aber keine direkte Stelle gefunden, die Allah ausdrücklich mit genau dieser festen Form bezeichnet.

**Urteil:** `unresolved`, sichtbar lassen.

### 65 · Al-Mājid vs. ID 48 Al-Majīd

Die App hat aktuell für beide lateinisch `Al-Majid`, obwohl das Arabische verschieden ist:

- ID 48: `الْمَجِيدُ` = **Al-Majīd**
- ID 65: `الْمَاجِدُ` = **Al-Mājid**

ID 48 ist durch Quran 11:73 direkt belegt. Für ID 65 wurde bisher kein gleich starker Einzelbeleg gefunden.

**Urteil ID 65:** `unresolved`.

**Spätere sichere UI-Aufgabe:** Nach Abschluss des gesamten Audit ein konsistentes Transliterationsschema definieren und diese beiden Formen sichtbar unterscheiden. Nicht jetzt nur einen Eintrag isoliert ändern.

### 67–68 · Al-Ahad / As-Samad

Quran 112:1–2:

- `قُلْ هُوَ اللَّهُ أَحَدٌ`
- `اللَّهُ الصَّمَدُ`

**Urteil:** beide direkt und stark belegt.

Hinweis zur Lernlisten-Zählung: Die verbreitete Aufzählung in Tirmidhi 3507 läuft in diesem Bereich anders als die App-Liste. Das ist kein Grund, `Al-Ahad` zu entfernen; der Name selbst ist durch Quran 112:1 sehr stark belegt. Die App soll die 99er-Zusammenstellung weiterhin als Lernliste und nicht als einzig fest überlieferte Reihenfolge kennzeichnen.

Das richtet sich direkt an Allah.

**Urteil:** beide starke Sahih-Einzelbelege.

### 77 · Al-Wali

Die App unterscheidet:

- ID 55 `الْوَلِيُّ` — Al-Waliyy, durch Quran 42:28 direkt belegt;
- ID 77 `الْوَالِي` — Al-Wali.

Diese Formen dürfen nicht aufgrund ähnlicher Umschrift automatisch gleichgesetzt werden.

**Urteil ID 77:** `unresolved` bis ein starker direkter Einzelbeleg für `الْوَالِي` vorliegt.
