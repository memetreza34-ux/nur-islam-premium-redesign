# Anfänger-Inhalte – fachliche Release-Abnahme

> **P0-Releaseblocker.** Diese Datei ist die fachliche Abnahme für den geführten Anfängerbereich. Eine vorhandene Quelle bedeutet noch nicht, dass Wortlaut, Kontext oder Übersetzung fachlich freigegeben sind.

## Freigaberegel

Der öffentliche Release darf die folgenden Inhalte erst als fachlich freigegeben behandeln, wenn pro Eintrag alle vier Punkte geprüft wurden:

- [ ] Aussage/Wortlaut fachlich korrekt und für Anfänger nicht irreführend
- [ ] Belegstelle passt tatsächlich zur Aussage
- [ ] Begriffe/Übersetzung/Transliteration sauber und verständlich
- [ ] Fiqh-/Aqidah-Unterschiede oder notwendige Einschränkungen korrekt gekennzeichnet

## Technische Release-Regel

Bis diese Abnahme abgeschlossen ist, bleiben alle Anfängerlektionen in `src/data/beginnerLearningContent.ts` auf:

```text
reviewStatus: 'needs-expert-review'
```

`npm run beginner:check` muss vor jedem Release erfolgreich sein. Der Check stellt sicher, dass die P0-Lektionen, Quellenblöcke, Review-Gates, Reinheitsgrundlagen, Anfänger-FAQ/Lexikon und der Quran-Anfängerpfad nicht versehentlich entfernt oder als bereits freigegeben behandelt werden.
